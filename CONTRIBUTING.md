# Contributing to MailPrime

First off, thank you for considering contributing to MailPrime! We welcome all types of contributions, whether it’s bug reports, feature suggestions, code contributions, or improving documentation. Your support helps us grow and improve.

---

## How to Contribute

### 1. Report Issues
If you encounter a bug or have a suggestion, please open an issue in the relevant repository. Make sure to include:
- A clear title and description.
- Steps to reproduce the issue (if applicable).
- Relevant screenshots or logs (if applicable).

### 2. Suggest Features
We’re always looking for ways to improve MailPrime. If you have a feature idea, create a feature request issue. Please include:
- The problem you’re solving.
- How the feature would work.
- Any potential challenges or alternatives.

### 3. Code Contributions
We love code contributions! To contribute code:
1. Fork the repository.
2. Create a new branch for your changes (e.g., `feature/new-email-template`).
3. Make your changes and write clear commit messages.
4. Push your branch to your fork.
5. Open a pull request (PR) to the `main` branch of the original repository.

#### Guidelines for Code Contributions:
- Follow the coding style and conventions used in the project.
- Write clear, concise, and self-documenting code.
- Ensure your changes do not introduce new bugs or break existing functionality.
- Include relevant tests for new features or bug fixes.
- Keep PRs focused and small for easier review.

### 4. Improve Documentation
Good documentation helps everyone! You can contribute by:
- Fixing typos or grammatical errors.
- Adding examples or improving explanations.
- Documenting new features or API changes.

### 5. Help with Discussions
You can also contribute by participating in discussions. Share your insights, review open PRs, or help answer questions from the community.

---

## Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/mailprime/<repository-name>.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
